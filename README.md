# TrendPulse creator-workflow prototype

Built by Arnav Ramesh in Pune, India. Started October 2026.

The Vercel deployment is a static React demo with eight sample trend cards, filters, local template-based briefs and a browser-local idea board. Metrics, example names and scores are illustrative, not live measurements. It does not currently provide live Claude API processing, MCP connectors, paid subscriptions, cloud accounts or an SLA.

Live feeds and server-side Claude integration are planned. The server directory contains development code and is not served by the current static Vercel configuration.

Contact opens an email draft; the website does not send inquiries. The domain mailbox is being set up.

## Development

Run `npm install`, then `npm run dev`. Build with `npm run build`.
